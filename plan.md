# ML手法の前にStrassen法でFLOPを減らす

確実に効くのは、Strassen 法で FLOP
を約3割減らすことです（主催者の許可が出ていると、参加者の投稿で報告されています）。以前「グレーなの
で確認が必要」と書いたのは訂正します。

### 調べて分かったこと

- リーダーボードの1位は 1.30e-9 でした（MSE 1.10e-8、C/B 約0.12）。お書きの 1.00e-9
より少し上です。上位10位はすべて 1.9e-9 以下で、MSE
を下げつつ予算の約1割しか使っていません。上位の手法は公開されていません。
- 締切は 10/21 23:59 UTC（あと約4.5日）です。提出は1日10回まで、最終提出の指定は 10/22
までに2件です。順位は新しい非公開の網で決まるので、公開データへの過学習は意味がありません。
- 評価器は flopscope 0.12.3 に更新されましたが、手元で測ったところ FLOP
は変わりませんでした（自作版 0.36991、V29 0.26706 で 0.12.1 と同じ）。
- 開発用の8網で、自作版と公開版（504aldo さんの MIT 公開コード）を比べました。

V29 は並列実行で時間切れになったため、MSE は V25
と同じ計算であることから推定しています。同じ計算量で、公開版は自作版より MSE が13%良い状態です。
- 最終層の ML
補正は、交差検証で約3.5%の改善でした。他の参加者の理論的な見積もり（最大4%）や実測（1%）とも合う
ので、ここで打ち切りました。
